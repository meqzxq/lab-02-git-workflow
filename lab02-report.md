|---|---|
| `git clone` | Клонування репозиторію |
| `git status` | Перевірка стану файлів |
| `git add` | Додавання змін до індексу |

## 5. Контрольні запитання

**1. Що таке Git?**

Git — розподілена система контролю версій, яка дозволяє відстежувати зміни у файлах та працювати з історією проєкту.

**2. Чим Git відрізняється від GitHub?**

Git — інструмент контролю версій, а GitHub — онлайн-платформа для зберігання Git-репозиторіїв і спільної роботи.

**3. Що таке коміт?**

Коміт — зафіксований стан змін у репозиторії з унікальним ідентифікатором та повідомленням.

**4. Для чого потрібні гілки?**

Гілки дозволяють розробляти функції незалежно від основної версії проєкту.

**5. Що таке Pull Request?**

Pull Request — запит на об'єднання змін однієї гілки з іншою з можливістю перегляду та обговорення коду.

**6. Що таке merge conflict?**

Конфлікт злиття — ситуація, коли Git не може автоматично узгодити несумісні зміни.

**7. Для чого потрібен .gitignore?**

Файл `.gitignore` визначає файли та папки, які Git повинен ігнорувати, якщо вони ще не відстежуються.

**8. Для чого використовуються теги?**

Теги позначають важливі точки історії, наприклад випуски версій програми.
